signature/TCC changes or copied proprietary implementation/assets. A bounded
host approval may answer the runtime's normal elicitation for explicitly
authorized fixture apps; it is not an unrestricted approval proxy.
Keep YA model-session coordination, MC testbed lifecycle and Sky GUI execution
separate. This is optional-provider qualification, not adoption or a repeated
performance comparison. Preserve unrelated concurrent keyboard-layout work.

### What actually worked

- The corrected adapter tolerates Claude's optional `server/discover` before
  ordinary MCP initialization, preserving the genuine tool documentation.
- Opus chose each app action. UI mutations used CUA tools; shell calls only
  verified files. No nested reasoning agent or alternate UI route appeared.
- Save produced the requested content and two distinct inline screenshots.
  An implicit binding and lowercase `return` initially failed; explicit binding
  and `Return` recovered. Both mistakes remain in the measured cost.
- Menu/conversion used Format, confirmation, File/Save As and the native chooser.
  It unchecked Keep changes in original document. Two distinct inline images
  returned, no tool errors occurred, and the independent oracle confirmed the
  source bytes and destination. This is a final-state preservation check.
- The genuine wrapper emitted 16 save and 21 menu approval requests, all for
  `com.apple.TextEdit`. The experiment host accepted this explicitly authorized
  app scope; no persistent Always allow decision was created. Decline behavior
  is protocol-tested, not live-tested against a denied second application.
- Both successful agents invoked `sky_close`, and child-runtime closure was
  recorded before guest disposal. No automatic restart cleared a native refusal.

### Cleanup and remaining limits

All four guests were discarded, their stored login credentials verified, and
their provisioning journals closed by the harness. Final inventory had no
experiment workspace or held claim; base and golden copy were stopped. The
experiment-scoped AAR client was revoked. Raw transcripts, screenshots, private
runtime/config pins and credential locators stay outside Git.

The adapter is an optional experiment route, not a supported general Sky SDK or
YA product integration. General app-approval UI, live decline/revocation and
physical-stop behavior, concurrent callers, other applications, fresh runtime
installation, other versions/platforms and locked use remain unqualified.
Machine Control's existing locked-use product is separate and was not retested.
No public bridge was installed; the observed integration needs protocol
adaptation and scoped host approval, not binary patching or a delegated Codex
model. A future matched Opus/Sky performance arm must freeze these choices first.

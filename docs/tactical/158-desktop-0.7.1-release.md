do not add a Windows/Linux GUI matrix or post-publication monitoring.

- Versioned notes and a clean main source matching origin.
- Successful unified six-target candidate and applicable source checks.
- Exact packaged Mac acceptance and verified disposable-workspace cleanup.
- One release-script invocation promoting those bytes, then report queued

release acceptance, or claim physical-input and cross-platform GUI evidence
from deterministic checks. Browser foreground opt-ins retain the interference
limit recorded in the owning topic. Raw evidence and credentials stay private.

artifact and run the required controller wrapper at its existing minimum:
three browser cycles, 120-second soak, 900-second expiry, at least 960-second
same-owner renewal, fault recovery and the separate visible Stop/boot scope.
Journal and verify disposal; do not substitute earlier source evidence.

### 3 — queue publication

Run the official three-argument release script once with the accepted candidate
and receipt. Record sanitized execution evidence and dispatch identity. CI owns
publication; no download/install check or monitoring is requested.

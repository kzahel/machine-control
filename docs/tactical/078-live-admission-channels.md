activation acceptance and full resource fencing on every governed action.
Provide standalone cancellable CLI/SDK use with parent-exit cleanup, retain
legacy fail-fast claims, and disclose the existing cooperative same-user grant

2. Enforce scope and current session/generations before provider dispatch, refuse
   unbound legacy effects while reserved, fence established raw browser sessions,
   and report interrupted already-dispatched effects as uncertain.
3. Add asynchronous initial Mac framing so a stalled caller cannot block Pause
   or other owners; provide pass-through activity monitoring with existing
   permission and thread-visible cancellation during native input dispatch.
4. Add local/remote transport proxies and standalone `control call` plus Python
   context manager. Check selected claims before activation/dispatch and during

5. Prove independent effect counters, foreign-session refusal, composed pauses,
   fresh activation, expired offers, dead parents, unknown activity, strict
   numeric types, cancellation, framing and bounded storage. Cross-build native
   artifacts; qualify live signed installations in the coordinating tactical.

## Objective and completion conditions

Let a verified live native session request a finite covered task using an
already approved, prepared console. Require both native session trust and the
independent explicit console consent; neither can replace the other. Prove
refusal without either, current console/scope/Stop fencing, independent effects,
relock, quiet resumption and retained Until-off consent.

## Boundaries

Automatic native trust alone remains ordinary local unlocked desktop access.
The additive `preparedConsole: true` request composes that identity with existing
observation/control consent and the existing enabled locked-use helper. It
creates no OS grant, unlock arming, administrator authority or broader scope.
Direct unlock, protected dispatch, browser/devtools and outer recovery remain
outside this profile. Open lid, awake, existing console only. Do not relax the
finite covered-session or guardian watchdogs.

3. Use the existing connection-owned covered lease and relock cleanup. Pause

## Validation and result

**Current, source implemented:** `preparedConsole: true` requires verified native
observation/control identity, separate active console consent and existing
helper preparation. Admission and dispatch recheck both authorities; helper
readiness is checked at activation. The existing connection-owned covered lease
performs unlock, capture exclusion, interruption and relock. Direct unlock and
protected dispatch remain denied. CLI/SDK opt in explicitly; legacy frames omit
the new field. Profile/status distinguish this composition from trust alone.

Console authority now binds before browser/availability observers can inspect a
new grant. Consent restoration carries its verified restoring-console state
through that same ordering, preventing premature inspection of a new grant
against an older binding.

**Current, fixture evidence:** 141 Swift tests and 179 client tests pass, including
missing/narrow consent, unprepared helper, scope/type validation, native revocation
and pre-dispatch fencing. Mac static checks, source UI typecheck, native deployment
and fresh doctor pass. These do not prove a signed covered task or real hardware
interruption.

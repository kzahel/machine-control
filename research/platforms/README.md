# Platform Research Index

Platform reports examine depth: the best available administration, semantic,
capture, input, browser, shell, session, privilege, and recovery routes for one
operating system or device family. They compare provider dossiers without
requiring one library to win everywhere.

| Platform | Current research posture |
| --- | --- |
| [Windows](windows.md) | First complete vertical slice; Cua and WinApp have live evidence |
| [macOS](macos.md) | Cua has live evidence; several strong exact-window references are source-reviewed |
| [Linux](linux.md) | AT-SPI foundation; X11 and each Wayland compositor require distinct evidence |
| [ChromeOS](chromeos.md) | Existing testbed is the North Star desktop reference |
| [iOS](ios.md) | CoreDevice plus Agent Device/XCTest is already adopted |
| [Android](android.md) | ADB is the mature foundation; semantic adapter shape remains to normalize |

These reports own research comparison, not lifecycle policy. The corresponding
authoritative testbed remains the source of operational truth.

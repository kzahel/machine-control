This extension lets an AI agent use Chrome through the Machine Control app on this computer, only while you allow it. Open this panel any time from the Machine Control button in the toolbar; pin it from the extensions menu to keep it visible.

Finish setup

  1. Install the Machine Control app for your computer.
  2. Open the app and turn on Browser in its setup checklist.
  3. Keep the app running. This panel turns green when Chrome is connected.

Access

Grant, extend and stop access in the Machine Control app. The toolbar badge shows ON for browser control and DEV for full DevTools access.
